ADRIAN AI VIDEO - ANDROID PROJECT

This project wraps the existing Adrian AI Video HTML demo in an Android WebView.

Build:
1. Open this folder in Android Studio.
2. Let Gradle sync/download Android Gradle Plugin dependencies.
3. Build > Build APK(s).
4. Install the generated app-debug.apk on your Android phone.
